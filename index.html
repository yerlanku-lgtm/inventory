Подключение Google Sheets
Вставьте URL вашего Apps Script Web App. Он будет принимать данные и записывать в Google Sheets. Инструкция ниже.
Как подключить Google Sheets
Откройте Google Sheets → Расширения → Apps Script
Скопируйте код ниже и вставьте в редактор
Нажмите «Развернуть» → «Новое развёртывание» → Тип: Веб-приложение
Доступ: Все → Развернуть → Скопировать URL
Вставьте URL в поле выше и сохраните
